# SmartHaul

Sitio público de **SmartHaul**, la aplicación de S3AM Perú para estimar el ciclo de acarreo, el esponjamiento del material y la flota de volquetes. Sirve la presentación de la app, la política de privacidad y los términos y condiciones.

La página tiene tema claro y oscuro, en español e inglés. El texto legal está vigente desde el 8 de noviembre de 2026.

## Páginas

| Archivo | Contenido |
| --- | --- |
| `index.html` | Presentación de la app |
| `privacy.html` | Política de privacidad |
| `terms.html` | Términos y condiciones |
| `delete-account.html` | Eliminar la cuenta y los datos asociados |
| `delete-data.html` | Eliminar una simulación sin borrar la cuenta |

Con GitHub Pages activado en la rama `main` y la carpeta raíz, las direcciones quedan así:

- https://s3am-sac.github.io/smarthaul/
- https://s3am-sac.github.io/smarthaul/privacy.html
- https://s3am-sac.github.io/smarthaul/terms.html
- https://s3am-sac.github.io/smarthaul/delete-account.html
- https://s3am-sac.github.io/smarthaul/delete-data.html

En la ficha de Google Play, la política de privacidad es `privacy.html`. La URL de eliminación de cuenta es `delete-account.html` y la de eliminación de datos es `delete-data.html`.
